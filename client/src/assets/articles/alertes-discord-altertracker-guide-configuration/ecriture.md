# Comment configurer et utiliser les alertes Discord sur AlterTracker

Les alertes Discord d'AlterTracker vous permettent de rester informé en temps réel des opportunités qui vous intéressent. Ce guide vous explique comment les configurer et les utiliser efficacement.

## Prérequis et configuration initiale

### Étape 1 : Créer votre compte AlterTracker

Pour commencer, vous devez créer un compte sur [AlterTracker](https://altertracker.com) avec une adresse email valide. Cette étape est essentielle pour accéder à toutes les fonctionnalités d'alertes.

### Étape 2 : Rejoindre le Discord AlterTracker

Avant de lier votre compte Discord, il est **crucial** de rejoindre le serveur Discord d'AlterTracker. Cette étape doit être effectuée avant la liaison de compte pour que l'attribution automatique du rôle fonctionne correctement.

![Rejoindre le serveur discord](assets/articles/alertes-discord-altertracker-guide-configuration/join_discord.png)

### Étape 3 : Lier votre compte Discord

Une fois sur le serveur Discord :

1. Accédez à votre profil sur AlterTracker
2. Dans la section de liaison Discord, connectez votre compte Discord à votre compte AlterTracker
3. Un rôle "utilisateur" vous sera automatiquement attribué sur le Discord

![Link discord à votre profile AlterTracker](assets/articles/alertes-discord-altertracker-guide-configuration/profile.png)

⚠️ **Important** : Assurez-vous d'avoir rejoint le Discord avant de procéder à la liaison, sinon l'attribution du rôle ne fonctionnera pas, dans le cas contraire vous avez juste a unlink votre compte Discord dans votre page profile, rejoindre le serveur Dsicord puis relink votre compte, si vous avez le rôle "utilisateur" c'est que la configuration est ok.

### Étape 4 : Configurer les paramètres Discord

Dans les paramètres de confidentialité du serveur Discord AlterTracker :

1. Accédez aux paramètres du serveur AlterTracker
2. Autorisez les **Messages Privés depuis le serveur Discord**
3. Cette configuration est nécessaire pour recevoir les notifications

![paramètres de confidentialité](assets/articles/alertes-discord-altertracker-guide-configuration/confidentialite_discord.png)

### Étape 5 : Tester vos alertes

Une fois la configuration terminée, vous pouvez tester que les alertes fonctionnent correctement en utilisant la fonction "Envoyer un ![alt text](image.png)message test" disponible dans votre profil AlterTracker.

![Message de test](assets/articles/alertes-discord-altertracker-guide-configuration/test_message.png)

## Types d'alertes disponibles

### 1. Alertes sur vos cartes favorites ❤️

**Comment ça fonctionne :**
- Cliquez sur le cœur d'une carte pour l'ajouter à vos favoris
- La carte apparaît automatiquement dans votre section "Alertes"
- Vous recevrez des notifications pour :
  - Ajout de nouvelles offres
  - Modification d'offres existantes
  - Disparition d'offres

![Carte favorite](assets/articles/alertes-discord-altertracker-guide-configuration/fav.png)

### 2. Alertes sur les réponses à vos offres 💬

Recevez une notification instantanée lorsqu'un possesseur de cartes répond à une de vos offres d'achat.

### 3. Alertes de recherche 🔍

#### Nouvelles cartes correspondant à vos recherches
Soyez notifié lorsque le script d'alimentation d'AlterTracker ajoute une nouvelle carte correspondant à vos critères de recherche.

![Recherche favorite](assets/articles/alertes-discord-altertracker-guide-configuration/search_alert.png)

#### Recherches favorites (mode bulk)
**Fonctionnalité avancée :**
- Disponible pour toutes les recherches avec moins de 1000 résultats
- Permet de mettre en favoris toutes les cartes d'une recherche en une seule fois
- Vous bénéficiez alors des mêmes fonctionnalités que les favoris individuels
- Idéal pour surveiller un large panel de cartes d'un coup

![Recherche favorite](assets/articles/alertes-discord-altertracker-guide-configuration/search_fav.png)

## Conseils d'utilisation

### Optimiser vos alertes
- Utilisez les recherches favorites pour les collections complètes
- Favorisez individuellement les cartes rares ou spécifiques
- Testez régulièrement vos notifications pour vous assurer qu'elles fonctionnent

### Gestion des notifications
- Ajustez vos paramètres Discord pour éviter le spam
- Organisez vos favoris par priorité
- Utilisez les filtres de recherche pour des alertes plus précises

## Dépannage

Si vous ne recevez pas d'alertes :

1. Vérifiez que vous avez bien rejoint le Discord avant la liaison
2. Confirmez que les messages privés sont autorisés
3. Testez avec la fonction "message test"
4. Vérifiez que votre rôle "utilisateur" est bien attribué sur le Discord
5. N'hésitez pas à poser vos questions sur le serveur Discord

## Conclusion

Les alertes Discord d'AlterTracker sont un outil puissant pour ne manquer aucune opportunité sur le marché des cartes. Une fois configurées correctement, elles vous permettront de réagir rapidement aux offres qui vous intéressent et d'optimiser vos achats et ventes.

N'hésitez pas à expérimenter avec les différents types d'alertes pour trouver la configuration qui correspond le mieux à vos besoins !
