Introduction à AlterTracker

AlterTracker est votre allié indispensable pour naviguer dans l'univers d'Altered TCG. Cette plateforme vous offre tous les outils nécessaires pour rechercher, suivre et gérer vos cartes efficacement.

Créer et configurer votre compte

Inscription gratuite

La première étape est de créer un compte gratuit qui vous donne accès à :

  • Sauvegarde de vos recherches personnalisées
  • Système d'alertes de prix en temps réel
  • Gestion complète de votre collection
  • Système de messagerie avec la communauté
  • Accès aux statistiques avancées

Configuration du profil

Personnalisez votre profil pour une expérience optimale :

  • Définissez vos factions préférées
  • Configurez vos alertes par défaut
  • Choisissez votre devise (EUR, USD, etc.)

Maîtriser la recherche avancée

Filtres de base

  • Nom/Référence : Recherchez par nom complet ou code ALT_
  • Faction : Filtrez par couleur (Axiom, Bravos, Lyra, etc.)
  • Rareté : Commun, Rare, Unique
  • Set : Choisissez l'extension désirée

Filtres avancés

  • Coût de mana : Définissez une fourchette précise
  • Statistiques : Force, PV, effets spéciaux
  • Effets : Recherchez par mots-clés dans les descriptions
  • Prix : Fourchette de prix pour cibler vos achats
  • Disponibilité : Cartes en stock uniquement

Opérateurs de recherche

Utilisez des opérateurs pour des recherches précises :

  • "texte exact" pour une correspondance exacte
  • +terme pour inclure obligatoirement un terme
  • -terme pour exclure un terme

Système d'alertes intelligent

Types d'alertes disponibles

  • Prix cible : Notification quand une carte atteint un prix défini
  • Nouvelles cartes : Alerte pour les nouvelles sorties
  • Stock disponible : Notification quand une carte rupture revient
  • Variation de prix : Alerte sur les hausses/baisses importantes

Configuration des alertes

  1. Définissez vos critères de recherche
  2. Cliquez sur "Créer une alerte"
  3. Choisissez le type de notification (Discord, email, in-app)
  4. Définissez la fréquence de vérification

Intégration Discord

Pour recevoir vos alertes instantanément sur Discord :

  1. Rejoignez le serveur Discord AlterTracker
  2. Allez dans vos paramètres de compte
  3. Cliquez sur "Lier Discord"
  4. Autorisez les permissions nécessaires
  5. Configurez vos préférences de notification

Gestion de votre collection

Méthodes d'import

  • Extension navigateur : Import automatique depuis les sites de vente
  • Import manuel : Ajout carte par carte
  • Import CSV : Pour les grosses collections
  • Scan QR : Fonctionnalité à venir

Organisation de la collection

  • Triez par faction, rareté, ou valeur
  • Créez des dossiers personnalisés
  • Marquez vos cartes favorites
  • Suivez la valeur totale en temps réel

Utiliser le Live Market

Fonctionnalités du Live Market

  • Prix en temps réel : Synchronisation automatique avec les vendeurs
  • Comparateur de prix : Trouvez les meilleures offres
  • Historique des prix : Graphiques de l'évolution sur 6 mois
  • Prédictions : Tendances basées sur l'IA

Interpréter les graphiques

  • ■ Ligne verte : Tendance haussière
  • ■ Ligne rouge : Tendance baissière
  • ● Points orange : Événements marquants (tournois, sorties)

Conseils et astuces d'expert

Optimisation des recherches

  • Sauvegardez vos recherches fréquentes avec des noms explicites
  • Utilisez les groupements pour organiser vos résultats
  • Activez les notifications push pour les alertes urgentes

Stratégies d'achat

  • Définissez des alertes réalistes (pas -50% du prix actuel)
  • Surveillez les tendances avant les tournois majeurs
  • Profitez des baisses post-rotation de formats

Gestion de portefeuille

  • Diversifiez vos investissements entre factions
  • Consultez régulièrement vos statistiques de collection
  • Utilisez les graphiques pour identifier les cycles de prix

Fonctionnalités avancées

API et intégrations

Pour les utilisateurs techniques, AlterTracker propose :

  • API REST pour intégrer les données dans vos outils
  • Webhooks pour les alertes personnalisées
  • Export de données en différents formats

Analyse statistique

  • ROI de votre collection
  • Performance par faction
  • Comparaison avec le marché global

Support et communauté

Obtenir de l'aide

  • Discord : Support communautaire 24h/24
  • Documentation : Guides détaillés en ligne
  • Tickets : Support technique direct

Contribuer à la communauté

  • Partagez vos listes de cartes publiques
  • Participez aux discussions sur les prix
  • Signalez les erreurs ou bugs rencontrés

Conclusion

AlterTracker est bien plus qu'un simple tracker de prix. C'est un écosystème complet pour les passionnés d'Altered TCG. Prenez le temps d'explorer toutes ses fonctionnalités pour maximiser votre expérience de jeu et d'investissement.
