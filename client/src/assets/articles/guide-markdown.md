# Guide de rédaction d'articles

## Structure recommandée

1. **Titre principal** (`#`)
2. **Citation d'introduction** (`>`)
3. **Sections avec sous-titres** (`##`, `###`)
4. **Conclusion**

## Éléments disponibles

### Boxes spéciaux

```markdown
<div class="tip">
Conseil utile
</div>

<div class="warning">
Attention importante
</div>

<div class="info">
Information générale
</div>

<div class="success">
Succès ou bonne pratique
</div>
```

### Tableaux

```markdown
| Colonne 1 | Colonne 2 |
|-----------|-----------|
| Données   | Données   |
```

### Code

```markdown
\`code inline\`

\`\`\`javascript
// Bloc de code
const exemple = "code";
\`\`\`
```

### Images

```markdown
![Description](url-image)
```
